# Convite da Milena

Site estático do convite da Milena.

## Como visualizar

1. Abra esta pasta no Visual Studio Code.
2. Abra o arquivo `index.html`.
3. Use a extensão **Live Server** e selecione **Open with Live Server**.

Também é possível abrir o `index.html` diretamente no navegador.

## Estrutura

```text
convite_milena/
├── index.html
└── assets/
    ├── audio/   # trilhas e efeitos sonoros
    ├── css/     # estilos da página
    ├── img/     # personagens, cenários e ícones
    └── js/      # interações do convite
```

- `index.html`: estrutura e conteúdo do convite.
- `assets/css/style.css`: aparência e responsividade.
- `assets/js/script.js`: animações, áudio e interações.
